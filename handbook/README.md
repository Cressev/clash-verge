# handbook

这里按章节存放 Clash Verge 代理网络问题检修手册。每个章节单独一个文档，避免把长文塞进单一文件里。

## 当前章节

- `01-overview.md`: 问题背景、核心判断和适用范围
- `02-diagnosis-order.md`: 诊断顺序与最短路径
- `03-dns-layer.md`: DNS / fake-ip / nameserver policy
- `04-rules-layer.md`: 规则层、进程规则、域名规则、IP-CIDR
- `05-tun-layer.md`: TUN 路由与 route-exclude
- `06-subscription-refresh-checklist.md`: 更新订阅后的复查步骤
- `07-macos-codex-path.md`: macOS 上 Codex / wrapper / 代理探针
- `08-windows-ssh-path.md`: Windows 上飞连 + Clash Verge + SSH
- `09-hysteria-wifi-capture.md`: zphz WiFi + Hysteria 的切前/切后采集流程

## 规则

- 一章一个文件。
- 章节内尽量只讲一个主题。
- 如果要补新经验，优先新增章节，不要把旧章节写得越来越臃肿。

# clash-verge

这个仓库是 Clash Verge / Feilian / Codex / SSH 网络问题的检修手册与脚本集。

## 目录

- `AGENTS.md`: 长期工作规则、路径约定、风险边界。
- `CURRENT.md`: 当前任务状态。
- `PROGRESS.md`: 阶段性进展摘要。
- `log.md`: 追加式工作日志。
- `TODOList.md`: 持久化任务追踪。
- `user-queries.md`: 用户请求入口。
- `handbook/`: 代理网络问题检修手册，每章单独成文。
- `script/`: 检查脚本、诊断代码和使用说明。
- `findings/`: 可复用的稳定发现。
- `reports/`: 仅在用户明确要求报告/归档时使用。

## 当前状态

仓库已初始化，第一版 handbook 和脚本骨架正在建立中。
